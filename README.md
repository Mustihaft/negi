# AI Video Studio — downloads

Windows 10/11 (x64) installers. This repository holds only the installers, no source code.

**Latest version:** https://github.com/Mustihaft/ai-video-studio-download/releases/latest

The installer is not code-signed yet, so Windows SmartScreen may warn: choose *More info → Run anyway*.
Each release lists the installer's SHA-256; check it in PowerShell with `Get-FileHash <file>`.
